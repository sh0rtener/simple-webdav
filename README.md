# Simple WebDAV

### Описание
Simple WebDAV - простое веб-приложения для удаленного доступа к файлам. По сути аналог NAS.

### Мотивация
Данный проект создан в личных целях для личного использования, в частности планировалось использовать его в домашней лаборатории (см. https://habr.com/ru/articles/822563/).
